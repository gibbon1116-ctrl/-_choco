# 勤務表メーカー

職員、勤務区分、希望休、日別の必要人数を登録し、Google OR-Tools CP-SATで1か月分の勤務表を自動作成するローカルアプリです。飲食店向けに、英語対応、新商品・商品カテゴリスキル、レジ・開店・閉店等の役割、繁忙日、スタッフ配置条件も扱えます。データはPC内のSQLiteに保存されます。

## 必要環境

- Windows 10 / 11
- Pythonのインストールは不要です。同梱の `python-3.12.8-embed-amd64` を使用します。(GitHubから直接使う場合はPython 3.12が別途必要です。「GitHubから取得して使う場合」を参照)
- アプリ利用時に外部サービスへ接続しません。

## セットアップ

次の構成を保ったまま、フォルダ一式をコピーしてください。別PCへ渡す場合も同じです。

```text
勤務表アプリ/
  python-3.12.8-embed-amd64/
  shift_scheduler_app/
  start_app.bat
```

`python-3.12.8-embed-amd64` フォルダには、アプリ起動に必要なPython本体とライブラリを同梱しています。

## 起動方法

`start_app.bat` をダブルクリックします。`shift_scheduler_app` フォルダ内の `run_app.bat` からも起動できます。黒い画面はアプリの実行中に必要なので閉じないでください。ブラウザが自動で開かない場合は、画面に表示される `http://localhost:8501` を開きます。

## GitHubから取得して使う場合

`python-3.12.8-embed-amd64` を含む配布フォルダ一式を使わず、GitHub上のソースコードから直接動かすこともできます。他のPCへ渡すときは、コピーするデータ量が少なく済みます。

### 事前準備

- そのPCに [Python 3.12](https://www.python.org/downloads/) をインストールします。インストール時に「Add python.exe to PATH」にチェックを入れてください。

### 手順

1. コードを取得します。
   - `git clone https://github.com/gibbon1116-ctrl/-_choco.git`
   - またはGitHubページの緑色「Code」ボタン→「Download ZIP」で取得し、展開します。
2. `shift_scheduler_app` フォルダ内の `setup_and_run.bat` をダブルクリックします。初回のみ仮想環境の作成とライブラリのインストールが自動で行われます(数分かかります)。2回目以降はそのままアプリが起動します。
3. ブラウザが自動で開かない場合は、画面に表示される `http://localhost:8501` を開きます。

この方法で入力したデータ(`data/shift_scheduler.sqlite`)はそのPC内だけに保存され、他のPCとは共有されません。GitHub上のコードが更新された後は、そのPCで `git pull` すれば最新版を取得できます。

## 最初に試す方法

1. 左メニューの「ホーム」を開きます。
2. 「サンプルデータを読み込む」を押します。
3. 「勤務表」を開き、事前チェックにエラーがないことを確認します。
4. 「勤務表を自動作成」を押します。
5. 勤務表、集計、希望・ルール確認、飲食店条件確認を確認します。
6. 「通常配布用」または「管理者確認用」を選び、Excelを出力します。

サンプルExcelは `sample_data` フォルダにも保存されます。職員12人、2026年8月の必要人数、希望休・固定勤務・避けたい勤務の例が入っています。

## 各画面

- **ホーム**: 対象年月の登録件数と最新結果を確認します。
- **職員マスタ**: 職員の追加・編集・削除、Excel取込・出力を行います。
- **勤務区分**: 日勤、早番、遅番、夜勤、休み等を管理します。
- **必要人数**: 日別・勤務区分別の人数を直接編集、または平日／土日テンプレートで一括設定します。
- **希望休・勤務希望**: off、avoid、prefer、fixedとhard／softを登録します。
- **店舗設定**: 飲食店モード、店舗名、営業時間、英語・新商品・アレルギー説明条件を設定します。
- **スタッフ配置相性設定**: 同時配置の優先・回避・禁止、教育係、繁忙時の組み合わせを管理します。管理者向け情報です。
- **新商品・イベント**: 商品キャンペーン、営業日、イベント日、繁忙度を登録します。
- **役割別必要人数**: 日付・勤務区分ごとに英語、レジ、開店、閉店、リーダー等の人数を設定します。
- **勤務表**: 事前チェック、自動作成、結果確認、Excel出力を1画面で行います。
- **Excel出力**: `outputs` フォルダへ通常配布用または管理者確認用を保存し、ブラウザからもダウンロードできます。

## Excel取込

画面の出力ボタンで作成したExcelと同じ列名を使用してください。日付は `2026-08-01`、対象年月は `2026-08` 形式を推奨します。入力ファイル自体は変更されません。

## Excel出力

完成した勤務表は `outputs` に保存されます。基本6シート（勤務表、日別配置、職員別集計、勤務区分別集計、希望休違反、ルール確認）に加え、飲食店条件確認、スタッフスキル一覧、新商品イベント一覧を出力します。管理者確認用だけに「相性条件確認」を追加し、通常配布用にはスタッフ配置条件を含めません。

勤務表セルの背景色には勤務区分マスタの `color` が使われます。

## 飲食店向けの設定手順

1. 「店舗設定」で飲食店向け条件を有効にします。
2. 「職員マスタ」の飲食店向けスキルで、英語、レジ、開店・閉店、商品スキル、新人・教育係等を登録します。
3. 「新商品・イベント」で商品期間と繁忙日を登録します。
4. 必要に応じて「役割別必要人数」と「スタッフ配置相性設定」を登録します。
5. 「勤務表」で自動作成し、「飲食店条件確認」に要確認項目がないか確認します。

一括登録用として `staff_skills.xlsx`、`staff_relations.xlsx`、`product_campaigns.xlsx`、`role_requirements.xlsx` を各管理画面から入出力できます。

## 主な制約

従来の絶対条件（1日最大1勤務、必要人数、夜勤可否、hard希望、最大連続勤務、夜勤明け休み）を維持しています。飲食店モードでは英語対応、役割別必要人数、同時配置禁止、新人だけの勤務禁止、開店・閉店対応をhard条件にできます。新商品初週、商品カテゴリ、配置の優先・回避、クローズ翌日オープン、アレルギー説明、ピーク対応はsoft条件としてペナルティを最小化します。重みは `config/rules.json` で変更できます。

## 作成できない場合

- 必要人数の合計が勤務対象職員数を超えていないか
- 夜勤可能者が不足していないか
- 同じ職員・同じ日に矛盾するhard希望がないか
- hard希望休や固定勤務が多すぎないか
- 月間最大勤務日数や最大連続勤務日数が厳しすぎないか

「自動作成」の事前チェックには、代表的な原因候補が表示されます。

## データとフォルダ

```text
shift_scheduler_app/
  app.py                 Streamlit画面
  config/rules.json      ペナルティ設定
  data/                  SQLiteデータベース
  sample_data/           取込用サンプルExcel
  outputs/               作成した勤務表Excel
  src/                   DB・ソルバー・検証・Excel・集計
  tests/                 自動テスト
  run_app.bat            Windows起動用(同梱Python)
  setup_and_run.bat      Windows起動用(GitHubから取得時、PC側のPythonを使用)
python-3.12.8-embed-amd64/
  python.exe             同梱Python
  Lib/site-packages/     同梱ライブラリ
start_app.bat            ルートフォルダからの起動用
```

データを初期化したい場合は、アプリを終了してから `data/shift_scheduler.sqlite` を別の場所へ退避してください。次回起動時に空のデータベースが作成されます。

## テスト

```powershell
..\python-3.12.8-embed-amd64\python.exe -m pytest -q
```
