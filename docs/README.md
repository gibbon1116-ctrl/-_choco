# ブラウザ版「勤務表メーカー」

このフォルダはドキュメント置き場ではなく、飲食店向け勤務表をブラウザだけで作成・管理するアプリ本体です。

フォルダ名が `docs` なのは、GitHub Pagesの「Deploy from a branch」機能で公開元として選べる場所が `/ (root)` または `/docs` に限られているためです。

## 起動方法

GitHub Pagesで公開されたURLへアクセスするだけで起動できます。Python、SQLite、npm、アプリのインストールは不要です。

データは利用中のブラウザのIndexedDBに保存されます。ブラウザやサイトデータを削除する前に、店舗設定の「データ管理」からバックアップをダウンロードしてください。

## 主な機能

- 職員、勤務区分、必要人数、希望休・勤務希望の登録
- 店舗スキル、スタッフ配置相性、新商品・イベント、役割別必要人数の設定
- Web WorkerとHiGHSによる勤務表の自動作成
- 勤務表の集計・条件確認とExcel入出力
- サンプルデータ、JSONバックアップ・復元、ブラウザ内へのデータ保存
